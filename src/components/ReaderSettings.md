# Reader settings content

Edits validated preference values through App callbacks. Konsta buttons and Range preserve original bounds, theme choices and capability gates. ReaderSheet owns focus and keyboard dismissal. Reading mode is provided by App above this content and remains open during changes. The range input has a native linked label.

The settings header precedes readingModeControl inside the same scroll panel. Following system appearance is the default and an explicit selectable option; choosing any concrete background writes followSystemTheme=false.

The optional WenKai choice appears only when the shared cache/decoder state is ready. Fixed-layout readers continue to hide typography controls.
