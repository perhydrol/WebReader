# Interface language

`i18n.ts` is the complete Chinese/English string table for the shelf, reader, settings, search, PDF tool, feedback dialog, and import errors.

- Chinese is the default and the language choice is stored by `App` in browser local storage under `webreader.language`.
- `TranslationKey` is derived from the Chinese dictionary; the English dictionary must implement every key.
- `translate` performs a local `{name}` substitution only. It never fetches strings or sends the current book/query.
- Format errors carry a `TranslationKey` so `App` can present them without importing UI copy into format detection.
- `markdownUnsupported` is the blocked-open message for legacy Markdown library rows; it states that data remains local and deletable.

Additional-font download, loading, retry, offline-cache and license labels are available in both languages.

The shared upload label explicitly describes clicking and dragging in both languages.

Feedback copy describes the external GitHub Issues destination, connectivity, account requirements and potentially public content.
